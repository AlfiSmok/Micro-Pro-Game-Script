# Micro-Pro-Game-Script
Opis plików: 
ets2-ats.cpp - Skrypt dla gier Euro Truck Simulator 2 / American Truck Simulator

farming-simulator-2025.cpp - Skrypt dla gry Farming Simulator 2025 (powinno działać zrównież z 22).

omsi2.cpp - Skrypt dla gry OMSI 2, przy powrocie z kierunku do stanu neutralnego sam zbija kierunek.

omsi2.cpp - Skrypt dla OMSI 2, przy powrocie z kierunku do stanu neutralnego nie zbija kierunku - zalecane gdy kierunek jest zbijany przez logike gry po przez skręt kierownicą.
